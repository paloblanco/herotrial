# Hero Trial — Accomplishment Board

150 accomplishments for the board (DESIGN.md §17). Edit freely: change wording, numbers, or swap entries out. Each one is written so the game can check it from counters it already tracks.

Terms used below:
- **Trial**: the 5-minute collecting phase. **Challenge**: the 90-second phase. **Ultimate**: choosing all 3 challenges.
- **Win**: finishing the chosen challenge(s) in time.
- **Total stats**: the sum of all 8 stats.
- **Knock out**: bring a hero to 0 HP or off the map.

Difficulty: ★ easy, ★★ takes some practice, ★★★ hard, ★★★★ very hard.
